## 🎯 프로젝트 개요

**Claude AI**와 **Figma**를 주요 도구로 활용하여 개발한 모바일 게임 프로젝트입니다. 전통적인 개발 방식 대신 AI-First 접근법으로 기획부터 배포까지 전 과정을 진행했습니다.

- 18x10 그리드 기반 숫자 매칭 퍼즐 게임
- React Native + Web 하이브리드 앱 구조
- AI 코드 생성 및 최적화로 개발 효율성 극대화

## 🤖 AI 활용 전략 및 성과

### 1. 개발 도구 및 AI 워크플로우

**주요 AI 도구**

- **Claude 3.5 Sonnet**: 코드 생성, 아키텍처 설계, 디버깅, 최적화
- **Figma + AI Plugin**: UI/UX 디자인 시스템 구축
- **GitHub Copilot**: 실시간 코드 어시스트

**기술 스택**

- `React 18.3.1` + `React Native + Expo` + `TypeScript`
- `Vite 6.3.5` + `Zustand 5.0.11` + `Tailwind CSS 4.1.12`

### 2. AI 기반 개발 프로세스

**🔄 반복적 AI 협업 방식**

1. **요구사항 정의** → Claude와 대화형 기획
2. **아키텍처 설계** → AI 추천 패턴 적용 및 최적화
3. **코드 생성** → Claude를 통한 컴포넌트/훅 생성
4. **디버깅** → AI 기반 에러 분석 및 해결책 제시
5. **리팩토링** → 성능 최적화 및 코드 품질 향상

**🎨 UI/UX 설계**

- Figma MCP를 이용한 디자인 파일 자동 생성 및 컴포넌트 추출
- Figma AI 플러그인으로 컬러 팔레트 자동 생성
- Claude를 통한 반응형 컴포넌트 디자인 시스템 구축
- AI 기반 접근성 가이드라인 적용
