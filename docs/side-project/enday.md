## 🎯 프로젝트 배경

**개발 기간**: 1.5주
**개발 동기**: 개인 영어 학습 필요성 → 직접 사용할 영어 일기 앱 개발

Claude Code CLI를 처음 접하며 AI 도구와의 협업 방식을 실험한 프로젝트로 기획부터 배포까지 단계별로 AI 도구의 활용도를 높여가며 개발.

## 🤖 개발 프로세스 및 AI 활용 전략

### 1. 기초 기획 (Figma Make + 개인 아이디어)

- **Figma Make**로 기본 와이어프레임과 사용자 플로우 설계
- 영어 일기 작성 → AI 검토 → 피드백 제공의 핵심 플로우 정의
- 디자인 시스템은 개발하며 점진적으로 구축하는 방향으로 결정

### 2. 프론트엔드 우선 개발 (Claude Code CLI)

- React + TypeScript 기반으로 UI/UX 먼저 구현
- Material-UI + Radix UI 조합으로 일관성 있는 컴포넌트 구축
- 개발하면서 디자인 시스템 정립 (색상, 타이포그래피, 간격)

### 3. 세부 기획 및 백엔드 연동 (Claude Code CLI)

- 기본 화면 구현 후 **Claude Code**로 세부 기획 이관
- **토큰 시스템**: 무료 사용자 일일 검사 제한 (수익화 모델 제안)
- **AdMob 연동**: 광고 기반 추가 토큰 지급 시스템 설계

### 4. 기술적 의사결정과 변경

- **AI 서비스**: OpenAI GPT → **Gemini** 무료 버전으로 변경 (비용 고려)
- **UI 라이브러리**: 단일 라이브러리 → Material-UI + Radix UI 조합 (기능별 최적화)

### 5. 마무리 및 디자인 polish (직접 코딩)

- Claude Code로 구현한 기능들의 세부 스타일링 직접 수정
- 사용자 경험 개선을 위한 애니메이션 및 인터랙션 추가
- 반응형 디자인 최적화

## 💻 기술 스택

**Frontend**

- React 18.3.1, TypeScript, Vite
- Zustand (상태관리), Tailwind CSS
- Material-UI + Radix UI

**Backend & Services**

- Supabase (인증, DB), Gemini API
- Vercel (배포)

## 🛠️ 핵심 구현 사항

### 1. AI 문법 검사 시스템

```
사용자 입력 → Gemini API 요청 → 문법 오류 탐지 → 교정 제안 표시
```

- 실시간 검사가 아닌 완료 후 검사로 API 비용 최적화
- 에러 핸들링: 네트워크 실패 시 로컬 저장 후 재시도

### 2. 토큰 기반 사용량 제한

- 일일 무료 토큰 3개 제공
- AdMob 광고 시청 시 추가 토큰 지급
- 토큰 소모 로직을 Zustand store로 관리

### 3. 데이터 관리

- Supabase RLS로 사용자별 데이터 격리
- 로컬 스토리지와 클라우드 동기화
- 오프라인 작성 지원

## ✏️ 개발 과정에서의 학습 포인트

### AI 도구 활용 전략 수립

- **단계적 AI 활용**: 기획 → 개발 → 세부 구현 → 최종 polish
- **도구별 적합성**: 기획은 Figma Make, 개발은 Claude Code, 디자인은 직접 작업
- **비용 최적화**: OpenAI → Gemini 전환으로 운영비 절감

### 실무 적용 가능한 패턴 학습

- AI API 통합 시 에러 핸들링 및 fallback 전략
- 토큰 기반 사용량 제한 시스템 설계
- 프론트엔드 우선 개발 후 백엔드 연동하는 워크플로우
